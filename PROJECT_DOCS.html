Tài Liệu Hệ Thống Quản Lý Nhà Sách

Phiên bản: 1.0 | Nhóm phát triển: Nhom22

1. Tổng Quan

Hệ thống Quản lý Nhà sách là một ứng dụng web giúp quản lý toàn diện các hoạt động của một nhà sách, từ việc nhập sách, quản lý kho, bán hàng, quản lý khách hàng cho đến việc lập các báo cáo doanh thu và tồn kho.

Công nghệ sử dụng:

  • Backend: Node.js, Express.js
  • Frontend: EJS (Embedded JavaScript templates), HTML5, CSS3
  • Database: SQL (Sử dụng Sequelize ORM)
  • Testing: Jest, Supertest

2. Cấu Trúc Dự Án

ROOT/

3. Chức Năng Chính

  • Quản lý Sách (Books): Tra cứu, thêm mới, nhập sách (Phiếu nhập sách), quản lý đầu sách và thể loại.
  • Quản lý Khách hàng (Customers): Lưu trữ thông tin khách hàng, quản lý công nợ.
  • Bán hàng (Sales):
    • Lập hóa đơn bán sách.
    • Tự động kiểm tra quy định (Số lượng tồn tối thiểu, Số tiền nợ tối đa).
    • Cập nhật kho và công nợ khách hàng tự động.
  • Thu tiền (Receipts): Lập phiếu thu tiền từ khách hàng để giảm nợ.
  • Báo cáo (Reports):
    • Báo cáo tồn kho (Tháng).
    • Báo cáo công nợ (Tháng).
  • Quy định (Rules): Thay đổi các tham số hệ thống (vd: Số lượng nhập tối thiểu, Tồn tối đa trước khi nhập...).

4. Tài Liệu API

Lưu ý chung:
  • Mã sách (MaSach) được tạo tự động theo format S001, S002...
  • Tất cả API trả về định dạng JSON nhất quán.
  • Hệ thống có kiểm tra ràng buộc khóa ngoại (Foreign Key) khi xóa dữ liệu.

Sách (Books)

Method Endpoint Mô tả
GET /books Lấy danh sách sách, hỗ trợ tìm kiếm.
POST /books/add Thêm sách mới (Yêu cầu MaDauSach tồn tại).

Hóa Đơn (Bills)

Method Endpoint Mô tả
POST /bills/add Tạo hóa đơn mới.
Body: MaKhachHang, Details (Mảng sách), TongTien...
Logic: Kiểm tra tồn kho > tồn tối thiểu sau bán, Kiểm tra nợ khách hàng < nợ tối đa.

Khách Hàng (Customers)

Method Endpoint Mô tả
GET /customers Danh sách khách hàng.
GET /customers/search Tra cứu khách hàng.

5. Hướng Dẫn Cài Đặt & Chạy

Yêu cầu hệ thống

  • Node.js (v14 trở lên)
  • MySQL (hoặc database tương thích Sequelize)

Các bước cài đặt

  1. Cài đặt dependencies: 
    npm install
  2. Cấu hình Database:

    Chỉnh sửa file config/db.js với thông tin đăng nhập database của bạn.

  3. Khởi tạo dữ liệu (Seeding):

    Chạy các script SQL trong thư mục scripts/ để tạo bảng và dữ liệu mẫu hoặc dùng lệnh (nếu có):

    node scripts/seedAdmin.js
  4. Chạy ứng dụng: 
    npm start

    Hoặc chạy với nodemon:

    node index.js

6. Test Cases & Hướng Dẫn Test

Dự án sử dụng Jest để thực hiện kiểm thử tự động (Automated Testing).

Các loại Test (Test Suites)

  • tests/business_logic.test.js: Kiểm tra các quy định nghiệp vụ cốt lõi (Quy định 4 về tiền nợ, Quy định 2 về tồn kho...).
  • tests/reports_rules.test.js: Kiểm tra tính chính xác của thuật toán báo cáo.
  • tests/books.test.js: Kiểm tra CRUD sách.
  • tests/users_customers.test.js: Kiểm tra luồng người dùng và khách hàng.

Cách chạy Test

Để chạy toàn bộ test cases:

npm test

Kết quả test sẽ hiển thị trên terminal và file báo cáo reports/junit.xml.
